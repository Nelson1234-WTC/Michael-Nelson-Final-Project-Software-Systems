AI Usage Ethics:
- AI is nondeterministic, while traditional software is deterministic.

Computer Fundamentals:
- A computer is a machine that receives input, processes information, stores data, and produces output
- An operating system (OS) is software that provides a platform for applications to run
Github:
- GitHub is a website that stores and manages code projects.
- Fork: your own copy of someone else's repository on GitHub.
Internet and Web Fundamnetals:
- An IP address identifies a device on a network. It works like a street address for computers.
- A domain name is a human-friendly website address, such as google.com or amazon.com
HTML Fundamentals:
-HTML stands for HyperText Markup Language.
- HTML is used to structure content on a webpage.
CSS Fundamentals:
- CSS stands for Cascading Style Sheets.
- CSS is used to style and layout webpages.
JavaScript Fundamentals:
- JavaScript is a programming language used to create interactive web pages.
- JavaScript can manipulate HTML and CSS to create dynamic content.
